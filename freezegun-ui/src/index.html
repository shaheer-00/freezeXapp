◤ FREEGUN · ABOUT ◢

freezeXapp is a chrono interdict deck — a Windows cyberdeck that freezes the clock for any process and severs its network egress.

How it works: A kernel-mode time-hook DLL (freezex.dll) is injected into target processes. The host writes a per-PID freeze schedule to a shared memory control block; injected hooks intercept time APIs (GetSystemTime, QueryPerformanceCounter, GetTickCount) and return frozen values.

Clock modes: FREEZE shifts the target clock −1h from real time (OFFSET mode). HALT/WAKE engages or disengages all hooks globally. NET adds a Windows Firewall outbound rule for the target's exe path (requires admin).

Freeze a running process? Click FREEZE on its row (or type freeze <pid>).
Freeze an app before it runs? Find it in Installed Apps below, click FREEZE — it launches, injects, then freezes.
Block internet for a process? Click NET on its row. Adds a firewall outbound rule by exe path (needs admin).
Unfreeze / unblock? Click UNFRZ or NET again to toggle back.
Pause everything? Type halt — all hooks pass through. wake re-engages.
